# Admin job details

Open a job in **Admin → Jobs** to inspect its generation settings. The top info
card shows the recorded model, resolution, video or audio duration, aspect ratio,
and other available parameters. Model identifiers remain visible alongside
recognized model names. Missing settings are omitted rather than filled with
assumed defaults.

**Processing time** measures the job's execution time; **Requested duration** is the
requested media length. The Input tab retains the full saved request for detailed
inspection.
